# Contributing

Thanks for helping improve the SDK.

## Before you start

- Read the README and the examples in `docs/examples`.
- Check the response samples in `docs/responses`.
- Keep changes small and focused.

## Code style

- Match the current TypeScript style in `src`.
- Keep comments short and human.
- Avoid adding extra complexity when a small fix works.

## Good pull requests

- Explain what changed and why.
- Include a test or a clear reason why one was not needed.
- Mention any behavior changes, especially around proxies, Playwright, or TikTok scraping.

## Local checks

Run the usual checks before opening a PR:

```sh
npm test
npm run typecheck
npm run lint
```

## Issues

- Use issues for bugs, ideas, and questions.
- Include the method you used, the input you passed, and the output or error you saw.
