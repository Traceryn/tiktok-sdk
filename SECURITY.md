# Security Policy

## Supported versions

Security fixes are tracked on the current main branch and the latest published release.

## Reporting a vulnerability

If you find a security issue, please do not post exploit details publicly.

- If GitHub Security Advisories are available for this repository, use that path first.
- Otherwise, open a normal issue with a short summary and mark it as sensitive if needed.
- Include the affected method, the input you used, and any logs that help explain the problem.

## What to include

- A short description of the issue.
- Steps to reproduce.
- The expected result and the actual result.
- Whether proxies, Playwright, or a specific host are involved.
